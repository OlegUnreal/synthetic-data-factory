# Demo recording

This folder is reserved for a short screen recording of the pipeline.

## What to record

1. Run the offline demo:
   ```bash
   python -m factory.demo
   ```
2. Show seeds loading, variants being generated, the judge dropping a low-scoring example, and the final JSONL export.
3. Keep it under 30 seconds.

## Tools

- Windows: Xbox Game Bar (`Win + G`) or OBS Studio.
- Convert to GIF with [ScreenToGif](https://www.screentogif.com/) or `ffmpeg`.

Save the final file as `docs/demo.gif` and it will render automatically below.
